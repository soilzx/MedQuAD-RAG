Retrieval-Augmented Healthcare Question Answering using Seq2Seq
-------------------------------------------
This project aims to develop a healthcare question-answering system using MedQuAD and FLAN-T5. The system will retrieve relevant medical information and generate a concise answer with its original source

##  Dataset

The project uses the MedQuAD dataset, loaded through Hugging Face.

- Total records: 47,441
- Usable question-answer pairs: 16,407
- Format: Medical questions and answers
- License: CC BY 4.0

##  Repository Files
-  data_analysis.ipynb: Loads and examines the MedQuAD dataset.
-  requirements.txt: Lists the required Python packages.
-  README.md: Provides project and setup information.
-  proposal: Where we record each milestone.
